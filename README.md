# MindPC

A local-first desktop tracker for Windows, macOS and Linux.

It records which application you are using and for how long, then shows your day on a dashboard.
**Everything is stored on your computer.** There is no account, no server and no network access, so it works fully offline.

## Architecture

| Layer | Tech |
|---|---|
| Desktop app + tracker | Electron (Node.js), `get-windows`, idle detection via `powerMonitor` |
| Storage | SQLite through Node's built-in `node:sqlite` (no native module to build) |
| Dashboard | React 19 + Vite + Tailwind CSS 3 + Recharts, loaded inside the app window |

```
Electron main process
  tracker (every 3s) -> sessionManager -> SQLite
        | IPC (preload.js)
React dashboard
```

```
mindpc/
  main.js / preload.js   – Electron entry points and the IPC bridge
  tracker.js idle.js     – polls the active window and idle time
  sessionManager.js      – pure session logic (tested)
  storage.js             – SQLite storage and queries (tested)
  dashboard/             – React UI
```

## Install

Download the installer for your system from the [Releases](../../releases) page:

| OS | File |
|---|---|
| Windows | `MindPC-<version>-win-x64.exe` |
| macOS (Apple Silicon / Intel) | `MindPC-<version>-mac-arm64.dmg` / `...-mac-x64.dmg` |
| Linux | `MindPC-<version>-linux-x86_64.AppImage` or `.deb` |

The installers are **not code-signed yet**, so your OS will warn you the first time:

- **macOS:** drag MindPC to Applications, then right-click it and choose **Open**. If macOS says the app is damaged, run `xattr -cr /Applications/MindPC.app` once.
- **Windows:** on the SmartScreen prompt choose **More info**, then **Run anyway**.
- **Linux:** for the AppImage, run `chmod +x MindPC-*.AppImage` and then start it.

## The app

- **Today:** your time so far against an optional goal, split into productive, neutral and distracting, with the last 7 days, your day as a strip, and every app and site you used. You can change any item's category.
- **Week:** totals compared with the 7 days before, each day, an hour-by-hour view of any day, and what you used most.
- **Apps & sites:** everything for today, 7 or 30 days, with search and a filter for apps or websites.
- **Settings:** recording on/off, start at login, daily goal, light or dark theme, the websites extension, export and delete.

## Run it from source

Requires Node 22+ and pnpm.

```bash
pnpm install
pnpm --dir dashboard install

pnpm start      # builds the dashboard and launches the app
pnpm dev        # dashboard with hot reload + app with auto-restart
pnpm test       # unit tests (app and dashboard)
```

## Build installers

```bash
pnpm dist:dir   # unpacked app in release/, fastest way to test packaging
pnpm dist       # installers for the current OS, in release/
```

Windows and Linux installers are built on their own OS: the `Build installers` GitHub Action builds all three.
Run it from the Actions tab, or push a tag (`git tag v0.1.0 && git push --tags`) to also create a draft release with every installer attached.
`pnpm smoke` starts the packaged app in `--self-test` mode and fails if it cannot launch; CI runs it on every OS after building.
Icons are generated by `pnpm icons` (`scripts/make-icons.js`).

## How it behaves

- Time is recorded only while you are active: after 5 minutes without keyboard or mouse input, the session ends at the moment you stopped.
- Sleep, screen lock and shutdown close the current session. A crash loses at most 3 seconds, and the interrupted session is recovered on next launch.
- A session that crosses midnight is split so each day gets only its own time.
- Closing the window keeps tracking in the tray. Pause or quit from the tray menu. **Pause is remembered**: if you pause and restart, tracking stays paused (the tray tooltip says "paused").
- MindPC's own window is never counted, so looking at the dashboard does not add to your screen time.
- If you used the first, server-based version, its saved history (`sessions-queue.json`) is imported once on first launch. The old version also recorded its own window while it was being developed; those rows are skipped. That version counted up to 5 minutes of idle time at the end of each idle period, so some old sessions run slightly long.
- On first run the installed app asks whether to **launch at login**. It then starts quietly in the tray. Change it anytime from the tray menu or the dashboard. (Not available when running from source.)
- Apps are sorted into **productive, neutral or distracting** using a built-in keyword list. It is a guess (a browser can be either), so you can change any app from the dashboard and your choice is remembered.
- An optional **daily goal** on total screen time sends a notification at 80% and at 100%, once each per day. It is off by default and worded as a break reminder.
- Raw sessions are kept for 90 days.
- **Export** writes your data to a JSON file, and **Delete data** removes it permanently.

## Websites (browser extension)

By default a browser is one lump ("Chrome"). The optional **MindPC Companion** extension (Chrome, Edge, Brave and other Chromium browsers) lets MindPC track each website as its own entry, whichever browser you used, so `github.com` counts as productive and `youtube.com` as distracting.

- It shares **only the site name** (`github.com`), never the page address, title or history, and ignores private windows.
- It talks only to MindPC on your own computer (`127.0.0.1`). A pairing code, shown in MindPC under **Browser sites**, stops anything else from sending data in; "New code" cancels every earlier pairing.
- Chrome describes its `tabs` permission as "Read your browsing history". That is how an extension is allowed to see the active tab's address; it is reduced to the site name before anything is sent.
- Without the extension everything works as before: time in a browser stays under the browser's name.

To connect it, open **Settings → Websites** in MindPC and press **Show extension folder**: MindPC copies the extension to a permanent folder and opens it. Then load that folder in your browser's extensions page (Developer mode → Load unpacked) and paste the pairing code shown in MindPC. More detail in [`extension/README.md`](extension/README.md). The extension is also attached to each release as `MindPC-Companion-<tag>.zip`.

## Platform notes

- **Windows / macOS:** supported through `get-windows`.
- **Linux:** the focused window is read through X11 with `xprop` and `xwininfo` (package `x11-utils`). The `.deb` installs it for you; with the AppImage, install it yourself (`sudo apt install x11-utils`). Wayland sessions may not report the active window.
- **macOS:** MindPC reads only the name of the active app, never window titles or URLs, so it does not ask for Accessibility or Screen Recording access.
- **Windows and Linux:** CI builds both installers and starts each packaged app in a self-test (database, active-window helper, bundled files). It has not been used on a real Windows or Linux desktop yet.
